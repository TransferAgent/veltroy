PART C — TypeScript Auth Routes
New file: server/routes/auth.ts

Four endpoints. All endpoints write to data/ndr.db via a shared SQLite helper server/db/authDb.ts (new file, uses better-sqlite3 or existing DB connection):

POST /auth/register

Body: { email, password, org_name, tier? }

Steps:

Validate email format and password strength (min 8 chars, 1 number, 1 special char).
Hash password with bcrypt (12 rounds).
Generate tenant_id = slugify(org_name) + "-" + nanoid(6) (e.g., acme-corp-x7k2m1).
Insert into ndr-tenants: tier="trial", is_trial=1, trial_expires_at = NOW + 6 days.
Insert into ndr-users: role="owner", is_parent=1, mfa_verified=0.
Call scripts/seed_trial_data.py --tenant_id=<id> via child_process.execSync. If seed fails, log error but do not fail registration.
Send welcome + OTP email via server/services/mailer.ts (see Part D).
Return 201 with { tenant_id, email, trial_expires_at, message: "Check your email to verify your account." }. Do not return JWT yet — require OTP verification first.
POST /auth/login

Body: { email, password }

Steps:

Look up user by email; return 401 if not found.
bcrypt.compare(password, password_hash); return 401 if mismatch.
Check user.status — if trial_expired, return 402 with { message: "Trial expired. Upgrade to continue.", upgrade_url: "/upgrade" }.
Generate 6-digit OTP, store in ndr-otp with expires_at = NOW + 10 min.
Send OTP email via mailer.
Return 200 with { message: "OTP sent to your email.", email }. No JWT yet.
POST /auth/verify-otp

Body: { email, otp_code }

Steps:

Look up latest unused OTP for email; return 401 if not found or expired.
Mark OTP as used=1.
Fetch user + tenant record.
Generate JWT (via generateToken() from jwtAuth.ts) with payload:
Copy{
  user_id:        user.id,
  email:          user.email,
  role:           user.role,
  ndr_tenant_id:  user.tenant_id,
  is_parent:      user.is_parent === 1,
  is_trial:       tenant.is_trial === 1,
  trial_expires_at: tenant.trial_expires_at,
  blueprint_version: "v1.2"
}
Return 200 with { token, user: { email, role, tenant_id, is_trial, trial_expires_at } }.
POST /auth/invite

Body: { email, role } — requires JWT, is_parent=true

Steps:

Validate JWT; confirm req.user.is_parent === true. Return 403 if not.
Validate role is one of: support, customer, billing_admin. Return 400 if owner/super_admin — parents cannot grant top-tier roles via invite.
Generate a temporary password (nanoid(12)).
Hash with bcrypt.
Insert ndr-users with same tenant_id as parent, is_parent=0, mfa_verified=0.
Send invite email via mailer: "You've been invited to [org_name]'s NDR dashboard. Temporary password: XXXX"
Return 201 with { email, role, tenant_id, message: "Invite sent." }.
