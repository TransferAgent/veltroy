Why This Design Is Correct
The two-pass approach solves the architectural constraint cleanly. The base JOIN at ±5 min acts as a funnel — it is intentionally permissive to avoid missing slow-burn attacks. The adaptive second pass then grades the quality of each correlation without discarding anything, giving the Engineer 4 kinetic layer a confidence signal to calibrate response intensity. A MEDIUM confidence IAM rotation alert can trigger a softer TIER 1 response while a HIGH confidence C2 beacon within a tight window triggers the full TIER 3.

This also future-proofs the platform: adding volume-based window contraction in Sprint 3 only requires updating ADAPTIVE_WINDOWS values at runtime — the architecture already supports it.
